1. What is NLP?
Natural Language Processing (NLP) is a branch of Artificial Intelligence that helps computers understand, process, and generate human language such as English, Hindi, and Gujarati. NLP is used in many applications we use every day. For example, WhatsApp uses NLP-related technology for features like message suggestions, translation, and understanding voice messages.

2. Three ways NLP makes AI smarter
1. Chatbots
NLP helps chatbots understand what the user is asking and provide a suitable response.
Example: A Swiggy chatbot can understand "Where is my order?" and provide the current order status.
2. Spam Detection
NLP helps email applications identify unwanted or suspicious messages.
Example: Gmail can analyze the words and content of an email and detect whether it is likely to be spam.
3. Sentiment Analysis
NLP can understand whether a user's text expresses a positive, negative, or neutral opinion.
Example: Zomato can analyze customer reviews such as "The food was amazing" and identify it as a positive review.

3. Tokenization using split()
Sentence:
I love ordering pizza from Zomato!

sentence = "I love ordering pizza from Zomato!"

tokens = sentence.split()

print(tokens)

Output : ['I', 'love', 'ordering', 'pizza', 'from', 'Zomato!']

4. Simple Sentiment Checker
We can create a basic sentiment checker using only Python.

review = input("Enter your movie review: ")

review = review.lower()

if "good" in review:
    print("Positive")
elif "bad" in review:
    print("Negative")
else:
    print("Neutral")

Example 1 : Enter your movie review: The movie was very good
Positive

Example 2 : Enter your movie review: The movie was bad
Negative

Example 3 : Enter your movie review: The movie was okay
Neutral

5. Simple Spam Filter
We need a function is_spam(email_text) that returns True when the email contains "win" or "free".

def is_spam(email_text):
    email_text = email_text.lower()

    if "win" in email_text or "free" in email_text:
        return True
    else:
        return False


# Test 1
email1 = "Congratulations! You win a free prize."
print(is_spam(email1))

# Test 2
email2 = "Your meeting is scheduled for tomorrow."
print(is_spam(email2))

True
False

Explanation
- Email 1 contains "win" and "free" → True → Spam
- Email 2 contains neither word → False → Not Spam
